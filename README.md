# Our Love Diary

Create a private mobile web app for a couple with a 4-digit PIN lock.

Features needed:

1. Header: Uploadable circular couple photo logo & "Days Together" counter.

2. Photo Gallery: Upload photos with captions, and a DELETE button on each photo.

3. Notes: Add love notes and DELETE them anytime.

4. Music: Add/embed Spotify links and DELETE/change them.

5. Games: 

   - Truth or Dare (with preloaded questions + ability to ADD and DELETE custom questions)

   - Real-time Tic-Tac-Toe

   - "How well do you know me?" Quiz

6. Birthday Surprise Tab: Countdown timer + "Open Surprise" button that pops confetti and shows a birthday letter.

Use Supabase free database for instant real-time sync between two phones. Aesthetic romantic dark theme.
